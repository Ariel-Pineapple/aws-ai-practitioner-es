# Dominio 1 — Aspectos básicos de IA y Machine Learning

Esta sección reúne los conceptos correspondientes al **Dominio 1: Aspectos básicos de IA y Machine Learning** de la certificación **AWS Certified AI Practitioner (AIF-C01)**.

El objetivo es comprender los fundamentos necesarios para identificar conceptos, casos de uso y las principales etapas del ciclo de vida de una solución de Machine Learning.

---

## 🎯 Objetivos de aprendizaje

Al finalizar este dominio deberías ser capaz de:

* Explicar conceptos fundamentales de Inteligencia Artificial y Machine Learning.
* Diferenciar los principales tipos de aprendizaje automático.
* Identificar casos de uso apropiados para IA y ML.
* Reconocer cuándo una solución de IA puede no ser necesaria.
* Comprender las principales etapas del ciclo de vida de Machine Learning.
* Identificar conceptos relacionados con entrenamiento, inferencia y evaluación.
* Interpretar las principales métricas utilizadas para evaluar modelos de ML.

## 🧭 Tasks del dominio

### Task 1.1 — Explique las terminologías y los conceptos básicos de la IA

Conceptos fundamentales de IA, ML, tipos de aprendizaje, inferencia y características generales de los modelos.

### Task 1.2 — Identifique casos prácticos de la IA

Selección de soluciones de IA y ML en función del problema empresarial.

### Task 1.3 — Describa el ciclo de vida del desarrollo del Machine Learning

Etapas necesarias para desarrollar, entrenar, evaluar, implementar y supervisar modelos de ML.
