# AWS Certified AI Practitioner (AIF-C01) — Guía de estudio en español

Guía de estudio y repositorio práctico en español (latinoamérica) para la preparación de la certificación **AWS Certified AI Practitioner (AIF-C01)**.

Este proyecto nace como parte de mi proceso personal de preparación para la certificación y tiene como objetivo organizar, explicar y reforzar los principales conceptos de **inteligencia artificial, machine learning e IA generativa en AWS**.

El contenido se irá construyendo progresivamente a partir del estudio de los dominios del examen, prácticas, laboratorios y análisis de conceptos que requieren mayor profundidad.

> **Nota:** Este repositorio es un proyecto educativo independiente. No contiene preguntas oficiales del examen ni pretende sustituir la documentación, formación o materiales oficiales de AWS.

---

## 🎯 Objetivo

Crear un recurso práctico en español que permita:

* Comprender los conceptos fundamentales de **IA y Machine Learning**.
* Entender los fundamentos de la **IA generativa y los modelos fundacionales (FM)**.
* Identificar los principales **servicios de IA/ML de AWS y sus casos de uso**.
* Comprender técnicas como **Prompt Engineering, RAG, Fine-tuning y Continued Pre-training**.
* Estudiar los principios de **IA responsable, seguridad, cumplimiento y gobernanza**.
* Practicar la toma de decisiones mediante escenarios similares a los utilizados en certificaciones de AWS.
* Documentar laboratorios y experimentos realizados durante el proceso de aprendizaje.

---

## 📚 Dominios del AIF-C01

La guía está organizada siguiendo los cinco dominios de conocimiento de **AWS Certified AI Practitioner**:

### 01 — Aspectos básicos de IA y Machine Learning

* Conceptos fundamentales de IA y ML
* Tipos de aprendizaje
* Inferencia
* Casos de uso
* Ciclo de vida de Machine Learning
* Overfitting y underfitting
* Bias y variance
* Métricas de evaluación

### 02 — Aspectos básicos de IA generativa

* Inteligencia artificial generativa
* Modelos fundacionales
* Large Language Models (LLM)
* Tokens
* Embeddings
* Parámetros de inferencia
* Context windows
* Capacidades y limitaciones de GenAI
* Infraestructura y servicios de AWS

### 03 — Aplicaciones de modelos fundacionales

* Prompt Engineering
* Zero-shot, One-shot y Few-shot prompting
* Retrieval-Augmented Generation (RAG)
* Vector embeddings
* Vector databases
* Fine-tuning
* Continued Pre-training
* Evaluación de modelos fundacionales

### 04 — IA responsable

* Fairness
* Bias
* Transparencia
* Explicabilidad
* Robustez
* Desarrollo responsable de sistemas de IA

### 05 — Seguridad, cumplimiento y gobernanza

* Seguridad de aplicaciones de IA
* Protección de datos
* Prompt Injection
* Controles de acceso
* Gobernanza
* Cumplimiento
* Servicios y mecanismos de seguridad de AWS

Una parte importante del repositorio estará dedicada a aprender a seleccionar el servicio adecuado según el problema que se desea resolver.

* Amazon Bedrock

* SageMaker Model Registry
* Amazon Q Business
* Amazon Lex
* Amazon Rekognition
* Amazon Comprehend
* Amazon Textract
* Amazon Transcribe
* Amazon Polly
* Amazon Kendra
* Amazon Personalize

El objetivo no será únicamente memorizar qué hace cada servicio, sino comprender **cuándo utilizarlo y cómo distinguirlo de alternativas similares**.
